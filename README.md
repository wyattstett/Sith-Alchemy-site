# Force Alchemy App v0.1.8

Static prototype for the Sith Alchemist Force Alchemy system.

Updates in v0.1.8:
- Fresh characters now start at character level 6 by default.
- New characters begin as a true blank slate: no recipes, no purchased nodes, no ingredients, no crafted items, no creatures, and no active projects.
- Setup no longer offers public demo/starter preload options.
- AP-affecting profile fields are locked outside GM Mode.
- AP remains auto-calculated from Sith Inquisitor level, Intelligence modifier, and GM Bonus AP.
- Test creature tools are GM-only.

Open `index.html` to run locally. Saves use browser localStorage.
